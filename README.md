# ASAGIRI DAYS｜朝霧高原観光ナビ

朝霧高原エリアに特化したスマートフォン向け観光案内アプリです。

## 主な機能
- 朝霧高原の観光スポット一覧
- 牧場 / グルメ / キャンプ / 自然 / 買い物 / 体験で絞り込み
- キーワード検索
- お気に入り保存
- 現在地利用
- Google Mapsで「現在地から行く」
- 簡易スポットマップ
- PWA対応

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルをすべてアップロード
3. Settings → Pages
4. Build and deployment を Deploy from a branch
5. Branch を main / (root) にして Save

## 注意
初期版です。営業時間・料金・休業日・予約条件などは変更されることがあります。公開前に各施設の公式情報を再確認してください。背景・カード写真には外部画像URLを使用しているため、恒久運用では権利確認済みの自前写真への差し替えを推奨します。
